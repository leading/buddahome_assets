# 默认微调与移动单行布局 · 2026-09-28

phone-compact-move.png 为连接的物理 iPhone 11 实拍，未使用模拟器。

- 新选择和重新展开工具条时，微调默认选中。
- 移动模式的 X/Y/Z、减号、数值、加号、重置排列在同一行；小屏或附加承托面选项超出宽度时可横向滚动，不增加工具条行数。

- 只读测量和截图，没有点击数值、重置或切换用户模式。调整数学、数值格式与重置基准的源码片段逐字节未变；微调控制器在工具条收起时继续保持挂载。
- layout.json 只含布局尺寸、静态按钮文案和检查布尔值，不含场景存档或实际物件坐标数值。
