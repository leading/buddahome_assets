# 编辑工具栏：手机实拍

[查看手机截图](phone-compact-water.png)

截图来自已连接的物理 iPhone 11（828×1792），不是模拟器或浏览器重绘。选中有水的石水钵时，三行浮条保留移动、旋转、缩放、高度、放置、清空水和微调；更多与多选使用标题栏入口。

- 手机布局实测：默认浮条 156pt，移动微调展开后 301pt；默认没有轴、数值和长说明堆叠。
- 微调开合保持原变换重置基准与相机；更多、重命名、放置共用单层弹窗。
- 验证多选、局部全选范围、整体/局部往返保留折叠状态，以及中英德文布局。自动检查阶段 scene/saved/draft 均保持不变。
- 此后检测到用户继续编辑，立即停止自动切换，不取消或覆盖新的未保存内容。
- 9 组独立能力检查覆盖直接选中容器清空、混合水/茶、空容器、供桌不代理清空后代和香灰开关；变换数学与改版前保持一致。

检查使用实际 React 回调和原生布局数据，不声称完成了物理手指自动化。没有在正在使用的手机上强制切换系统大字设置；App 仍锁定竖屏，不把受控或模拟器结果当作横屏真机验收。
