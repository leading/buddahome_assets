# 香烟雾浅白调色 · 2026-09-28

phone-white-smoke.png 为连接的物理 iPhone 11 实拍（828×1792），使用实际佛堂场景和生产烟雾合成通道。

- 近处烟丝由深灰改为柔和浅白，扩散烟雾同步提亮；所有香复用现有材质。
- 仅改两个 RGB 常量；透明度、噪声、粒子预算、漂移与消散、深度遮挡、半分辨率合成通道均未改动，茶杯热汽分支也未改动。
- 首轮定帧读回的烟雾 alpha 逐字节相同，相机与粒子数相同；两次均为 98 次绘制、57 个几何体、38 个纹理。首个旧材质读到一次来源未归因的 GL 错误标志；新材质为 0。后续暖机复核两种颜色的 GL 错误均为 0。
- 后续截图期间观察到手机视角变化，故不把第二轮图像或其像素/绘制统计作为固定机位对比；本次只发布最终浅白烟雾实拍。场景、保存和草稿签名未变，动画已恢复。
- 本次为调色回归，不以截图推断 GPU 帧时；没有增加生产渲染资源或额外通道。
