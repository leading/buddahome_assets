# Object preview and placement destination

Physical iPhone 11 captures. The object picker has no Add footer. Tapping a card opens its model preview with a destination selector, Cancel and Add to altar.

- phone-asset-selected-destination.png: the selected offering plate is the default destination.
- phone-asset-destination-options.png: existing compatible supports and containers use the shared destination list.
- phone-asset-independent.png: explicit independent placement.
- phone-asset-picker-return.png: cancellation retains search, selected card and scroll position.

The verification did not actually add or save any object. Original scene, saved scene, draft and camera were preserved. Pure-data checks cover 33 asset types and 528 compatible pairs across supports, container interiors, liquid containers and insertion interfaces; world contact anchors match target transforms.
