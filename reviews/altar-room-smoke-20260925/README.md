# 佛堂房间烟雾扩散 · 2026-09-25

room-7/20/45/90 为同一镜头点燃后的模拟秒数；without-room 是同一状态关闭房间薄雾层的对照。extinguished-10/30/60 是停止点燃后 10/30/60 秒。近景、设计距离、远景另有截图。

房间薄雾来自已经上升的香烟，世界坐标模拟横向空气流动和扩散。总上限 1024（细烟 960、房间薄雾 64），没有全屏灰色滤镜。此批次浏览器为固定时间步进和相机的隔离 Three.js 检查；iphone-room 系列为实际 iPhone 11 / Expo GL 的 GL 层截图，未修改用户布置。

带 v2 的浏览器图片为最终参数，不带 v2 的同名图片是第一版迭代记录。room-motion.gif 是六秒正常速度片段，room-motion-frames.jpg 是同段抽样；这些隔离浏览器画面保留此前场景副本中的物件位置，当前 App 构图应查看 iphone-room 系列。

iphone-room-lit 为持续点燃；iphone-room-residual 为熄灭 30 个模拟秒后的余雾；iphone-room-clear 为熄灭 65 个模拟秒后。真机调试曾超时，没有取回本轮最终耗时数据，因此图片不代表帧率验证。
