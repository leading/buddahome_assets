# 场景操作图标对比

[查看配色对照图](contrast-preview.png)

此图使用工程当前的 SVG 图标和共享配色，展示深色、浅色和复杂明暗样例；它是网页渲染的样式对照，不是手机实拍，也不是模拟器图。

- 首页顶部、编辑顶部与右下工具入口使用同一组半透明深色衬底和浅色图标，仅包住按钮区域。
- 按下/展开时局部变深；不可用图标降低前景强度，衬底不会一起淡掉。编辑确认按钮使用同系深橄榄色。
- 白色卡片、详情标题栏与菜单内部仍保持原样式。
- 126 项数值检查覆盖黑/白/原色/中灰底、三种衬底和普通/选中/按下状态，分别按 sRGB 与线性光合成计算。最低前景比值约 4.14，不可用图标约 3.04；这是计算检查，不是认证，也不保证任意环境光或 HDR 条件。
- 共用组件检查确认点击/禁用绑定保持一致、按钮 44pt、编辑顶部总高仍为 48pt、四个分组总宽 280pt，可放入 320pt 窄屏的现有边距。
- 手机连接时读取到三个首页图标均为新浅色；随后调试连接中断，本次未取得手机实拍。没有为验证而更换用户的背景或布置。
