## 规则与几何

- 清水不应用茶色吸收，不绘制半透明液体侧壳；茶和清水不会被静默改类型或混合。空容器不绘制水面。
- 64 个方向按已发布模型的实际内壁截面采样；复用既有 BVH，按几何与能力配置缓存。容量和高度继续读取已发布曲线，不修改资产或存档。
- 真机当前石钵与茶杯的场景副本在 10%、55%、100% 水量下检查贴壁采样点，最大偏差小于 0.003 mm（资产坐标）。动画复用缓冲，平均液面 CPU 更新时间约 0.51 ms；这不是 GPU 帧时或整机性能指标。
- 实际编辑组件验证：供桌、组合、未选中或空容器不显示清空；只有明确选中的有液体容器可清空，不遍历内部容器。清空是一条编辑事务，可撤销。
- 首页加水与清空只保存液体，镜头和布局不变。倾斜容器不加水，水与茶混用前需先清空。
